# SKY • Памятка Правительства (Vite + React + Tailwind)

## 🚀 Быстрый старт (Windows/macOS/Linux)

1) Установите Node.js LTS (18+): https://nodejs.org/
2) В терминале перейдите в папку проекта и установите зависимости:
```bash
npm install
```
3) Запуск локально (c авто‑обновлением):
```bash
npm run dev
```
Откройте адрес из терминала (обычно `http://localhost:5173`).

### 📱 Открыть на iPhone/Android
1) Узнайте IP вашего ПК в локальной сети (например, 192.168.1.10).
2) Запустите dev‑сервер доступным в сети (он уже настроен):
```bash
npm run dev
```
3) На телефоне в той же сети откройте `http://<IP>:5173` (пример: `http://192.168.1.10:5173`).

### 🧩 Что внутри
- Vite + React + TypeScript
- TailwindCSS (+ @tailwindcss/typography)
- lucide-react (иконки)
- Ваш компонент: `src/GovCheatsheetSky.tsx` (импортируется в `src/App.tsx`)

### 🏗️ Билд (готовая статика для хостинга)
```bash
npm run build
```
Готовые файлы появятся в папке `dist/`. Их можно залить на любой статический хостинг:
- **Vercel**: импортируйте репозиторий — автонастройка.
- **Netlify**: указать команду сборки `npm run build` и папку публикации `dist/`.
- **GitHub Pages**: соберите и задеплойте содержимое `dist/`.

### 🔧 Полезное
- Если порт занят, смените его: `vite --port 5174` или добавьте в `vite.config.ts`.
- Для доступа из локальной сети уже выставлен `server.host = true`.
- Все классы Tailwind уже работают — правьте стили прямо в JSX.

Удачи! 🎯

## Liquid Glass UI (iOS‑like)

В теме добавлены дизайн‑токены и стили «жидкого стекла» (мягкий frost/blur, тонкая 1px‑граница, лёгкий глянец, еле заметные ореолы фона).

Токены выставляются в ранней инициализации из `src/theme.ts` (без изменения публичного API) и применяются до первого кадра, meta `theme-color` синхронизируется.

Токены (CSS‑переменные):
- Фон/поверхности: `--bg-1`, `--bg-2`, `--surface-1`, `--surface-2`, `--surface`, `--card`
- Границы и текст: `--border-1`, `--border`, `--card-border`, `--text-1`, `--text-2`, `--muted`
- Акцент: `--accent`, `--accent-500`, `--accent-600`, `--accent-contrast`
- Фокус/тени: `--focus`, `--ring`, `--shadow-lg`
- Стекло: `--glass-blur` (радиус blur)
- Liquid «ореолы»: `--liquid-a`, `--liquid-b`

Режимы:
- Classic — фоновая картинка (если выбрана) остаётся.
- Liquid — фон строится из базового цвета и двух мягких радиальных «ореолов» (`--liquid-a`, `--liquid-b`), фоновые изображения отключаются.

Как применять «стеклянные» элементы:
- Карточка/панель: добавить класс `card` или использовать `liquid-glass` (для более выраженного стекла), пример:
  - `<div class="card">...</div>` — лёгкая стеклянная поверхность, граница 1px, мягкая тень.
  - `<div class="liquid-glass p-4">...</div>` — двухслойное стекло с глянцем и микро‑текстурой.
- Акцентная кнопка: класс `btn btn-primary` — плавный градиент `--accent`→`--accent-600`, текст контрастный по `--accent-contrast`.
- Фокусные состояния: используют оттенок акцента (`--focus`, `--ring`).

Производительность:
- В вьюпорте не более 2–3 крупных blur‑поверхностей; крупные секции — без blur (только цвет/градиент/тень).
- Анимации только transform/opacity (≈120–180 мс), есть поддержка `prefers-reduced-motion`.
- Поверхности `liquid-glass` локально изолированы (`contain: paint`) для уменьшения перерисовок.

Роутинг/загрузка:
- Основные маршруты уже разделены по коду (`React.lazy`).
- Предзагрузка вероятных переходов может быть добавлена в местах навигации (hover/intent) через динамические `import()` — по необходимости.

API темы:
- Публичный API `src/theme.ts` сохранён. Добавлены токены и их ранняя установка (инициализация в `initTheme()`), Liquid‑режим не использует фоновые изображения.
