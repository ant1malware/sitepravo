# UI Style Guide

Этот документ описывает базовые элементы дизайна, используемые на проекте.

## Цвета
- **Accent (`--accent`)**: `#6366F1` – основной цвет действий.
- **Фон `--bg-1` / `--bg-2`**: `#fafafa` и `#f4f4f5` в светлой теме.
- **Карточка (`--card`)**: `rgba(255,255,255,0.85)` с бордером `#e4e4e7`.

Пример:
```html
<button class="btn btn-primary">Действие</button>
```

## Типографика
Используются системные шрифты Tailwind (`font-sans`) с улучшенным сглаживанием.
Заголовки оформляются через стандартные теги `<h1>–<h4>`.

## Размеры и скругления
- `.rounded-2xl` – `1rem`
- `.rounded-3xl` – `1.25rem`
- Отступы и размеры берутся из стандартной шкалы Tailwind.

## Компоненты
### Карточка
```html
<div class="card">Контент</div>
```

### Кнопка
```html
<button class="btn">Обычная</button>
<button class="btn btn-primary">Основная</button>
```

### Поле ввода
```html
<input class="input" placeholder="Ваш текст" />
```

> При добавлении новых UI‑элементов обновляйте этот файл с примерами и описанием.
